# Test data

`GeoIP2-City-Test.mmdb` is the small City database from MaxMind's public test-data
repository (https://github.com/maxmind/MaxMind-DB/tree/main/test-data). It holds a
few dozen made-up-but-realistic records, not real GeoLite2 data. Check that
repository's license before redistributing it.

`GeoLite2-ASN-Test.mmdb` comes from the same repository and is the matching small
ASN database (same licence caveat).
